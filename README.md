# hxwl-01 助听器套餐与随访余次台

门店听力师的助听器套餐建档、随访扣次与续费版本管理工作台。

## 技术栈

React + Vite + TypeScript + CSS（数据保存在浏览器 localStorage，**无新增依赖**）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5101

## 业务规则

1. **新单登记**：每单登记客户、双耳机型、首配日、套餐次数与保修截止日；双耳分别建档、余次独立。
2. **在途冲突拒绝**：同一客户同一耳别已存在在途套餐（有余次且保修有效）时，新单拒绝登记；表单输入原样保留，并显示冲突的客户、耳别、剩余次数与命中规则。
3. **随访扣次**：每次随访扣减 1 次并记录日期与效果，计入当前套餐版本。
4. **排期拦截**：剩余次数为零或保修过期时不得排期随访，该耳自动转为「待续费」。
5. **续费版本化**：续费必须填写原因，新建套餐版本（首配日不变）；旧版本的次数与随访记录全部保留可查。
6. **刷新一致**：套餐、余次、随访与版本持久化在 localStorage，刷新后严格对应；侧栏可恢复示例档案。

## 代码分层

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 资料模型 | `src/types.ts` | 订单 / 双耳套餐 / 版本 / 随访类型 |
| 种子资料 | `src/seed.ts` | 示例档案（含在途、余次为零、保修过期三种情形） |
| 扣次与规则 | `src/domain/packageRules.ts` | 冲突判定、建档、随访扣次、续费版本、指标，纯函数 |
| 存储 | `src/storage/orderStore.ts` | localStorage 读写与重置 |
| 页面 | `src/components/*`、`src/App.tsx` | 表单、套餐卡、订单台账与看板 |
